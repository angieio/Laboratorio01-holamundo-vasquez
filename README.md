Android Studio y GitHub
Angieluz Kelly Vasquez Macalupu
Aplicación inicial desarrollada en Android Studio para el curso de Programación en Móviles. 
Este primer proyecto básico utiliza Kotlin como lenguaje de programación y Jetpack Compose.
Funciona como una práctica inicial para la configuración de proyectos Android y el uso de GitHub en el control de versiones.
